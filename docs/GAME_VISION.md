# GAME VISION

**BLOOD SPLATTER: NINE CIRCLES** is a first-person action roguelike.

## The pitch

You descend. Nine circles, each a run. Fast, loud, red.

## Pillars

**Movement first.** The game has to be fun with nothing in it. If running,
dashing and sliding around an empty box is not entertaining, no amount of
weapons or enemies will fix it.

**Aggression is rewarded.** Design pushes the player forward, never into cover.

**Mechanical mastery.** Depth comes from the player getting better at the same
verbs, not from the game handing out new ones.

**Readable chaos.** Whatever the screen is doing, the player always knows where
they are and what is about to hit them.

## Feel references

ULTRAKILL (speed, aggression, style), Hades (run structure, build variety),
The Binding of Isaac (item interactions, run-to-run variance), classic Doom
(arena flow, no reloading, no cover), hack'n'slash (combo pacing).

## Technical shape

Godot 4.7.2, Compatibility renderer, GDScript, PC / Steam. Must run on modest
hardware.

Art will start as 2.5D sprites and may later move to low-poly models. Nothing in
the codebase should assume either.

## Roadmap intent (not a schedule)

0. **THE BOX** — movement feel. *(current)*
1. Combat verbs and a single weapon.
2. One enemy, one chamber loop.
3. Procedural chambers.
4. Roguelike items and run structure.
5. The nine circles.

Steps 1+ are not being designed yet. Nothing in the current code should
pre-empt them.
